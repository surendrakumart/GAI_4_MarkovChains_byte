# GAI_4_MarkovChains_byte

A small, reproducible Python project that demonstrates statistical text generation with a word-level Markov chain. It learns word-transition patterns from a short corpus included in this repository and generates 20 samples from different starting-word prompts.

## Project contents

- `generate.py` — runnable Markov-chain generator, with configurable order, output length and random seed.
- `prompts.txt` — the 20 starting-word prompts used for the saved samples.
- `corpus/training_text.txt` — the source text used to build the transition model.
- `corpus/SOURCE_AND_LICENSE.md` — corpus provenance and reuse terms.
- `generated_samples/` — 20 text outputs generated by `generate.py`.
- `comparison_note.md` — brief comparison with neural text generation (under 200 words).
- `tests/test_generate.py` — small automated checks.
- `LICENSE` — license for the code in this repository.

## Requirements

- Python 3.9 or later
- No third-party Python packages are required.

## Run the generator

From the repository root, run:

```bash
python generate.py
```

The command reads `corpus/training_text.txt` and `prompts.txt`, then writes one file for each prompt to `generated_samples/`. The default configuration uses Markov order 3 and a fixed base random seed so the samples can be reproduced with the same code and corpus.

Optional arguments:

```bash
python generate.py --order 2 --tokens 45 --seed 2026
```

- `--order`: Markov order; default is `3`.
- `--tokens`: approximate maximum token count for each output before sentence-ending truncation; default is `55`.
- `--seed`: base random seed; default is `2026`.

To run the automated checks:

```bash
python -m unittest discover -s tests -v
```

## Method

The script tokenizes the corpus into lowercase words and basic punctuation. It records possible next tokens for contexts of one word up to `order - 1` words. During generation, it selects a continuation from the longest available context and backs off to shorter contexts if necessary. Each sample starts from its specified seed word. The program uses Python's standard library only.

## Results and limitations

The 20 saved samples show that Markov chains can reproduce local phrasing patterns in the input corpus. Because the model uses short token contexts, it may splice together unrelated clauses, repeat phrases, create awkward grammar, or lose long-range coherence. These outputs are illustrative statistical samples, not factual or semantic responses.

## Reproducibility note

The sample files in `generated_samples/` were generated by running the included script against the included corpus and prompt list. Re-running the command with the default options replaces the existing `sample_*.txt` files with deterministic outputs for this project version.
